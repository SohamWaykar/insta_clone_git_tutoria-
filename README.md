# 📸 Insta Clone (Git Tutorial Project)

This repository contains a simple **Instagram Clone** project that I created while learning and practicing **Git** and **GitHub** fundamentals.

The primary purpose of this project was not to build a complete Instagram clone, but to understand how version control works and how to manage a project's codebase using Git.

---

## 🎯 Objective

The goal of this project was to gain hands-on experience with:

- Initializing a Git repository
- Creating and managing commits
- Working with branches
- Merging branches
- Understanding Git workflow
- Pushing code to GitHub
- Pulling updates from remote repositories
- Resolving merge conflicts
- Managing project history using Git

---

## 🚀 Features

Although this is a basic practice project, it includes:

- Instagram-inspired UI layout
- Basic HTML and CSS structure
- Responsive design fundamentals
- Organized project folder structure
- Version-controlled development using Git

## 📚 What I Learned

During this project, I learned how to:

- Create a local Git repository
- Stage files using `git add`
- Commit changes with meaningful messages
- View commit history using `git log`
- Create and switch branches
- Merge branches into the main branch
- Push repositories to GitHub
- Clone repositories
- Pull the latest changes
- Handle merge conflicts
- Use `.gitignore`
- Understand the importance of version control in software development

## 💻 Getting Started

To run this project locally:

1. Clone the repository

```bash
git clone https://github.com/your-username/insta_clone_git_tutorial.git
```

2. Navigate to the project folder

```bash
cd insta_clone_git_tutorial
```

3. Open `index.html` in your browser.
